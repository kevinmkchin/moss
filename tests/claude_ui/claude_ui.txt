# Claude tabs made comfortable: the composer (a multi-line prompt, sent with Ctrl+Enter), a claude tab's conversation
# (markdown, a code block's copy button, the tools it used; its prompt box: a prompt sent, the turn coming in as it
# runs; a question shows the terminal), the account line (the model picker, the mode, the context), the sidebar's
# full-text search and its menu (pin, rename, archive). Claude is faked; its sessions are made up (make.py).
waitfor λ
type python make.py
key Enter
waitfor made
# --- the composer, on the shell: two lines, sent as two commands ---
key Ctrl+Shift+I
waitlabel composer
type echo comp^osed-one
key Enter
type echo comp^osed-two
sleep 300
waitidle
capture out/composer.png
key Ctrl+Enter
waitfor composed-two
waitgone composer
# --- a claude session from the sidebar: its account line (context, mode, model) ---
waitlabel session Show me the plan
cursorui session Show me the plan
lmb down
lmb up
waitfor fake-claude ready
waitlabel claude model
waitlabel chat prompt
waitlabel copy code 1
sleep 3500
waitidle
capture out/account_line.png
# the model picker types /model
cursorui claude model
lmb down
lmb up
waitlabel palette model sonnet
sleep 400
waitidle
cursorui palette model sonnet
lmb down
lmb up
waitfor heard: /model sonnet
# --- the conversation: markdown, a code block copied ---
waitlabel copy code 1
sleep 500
waitidle
capture out/reader.png

sleep 300
