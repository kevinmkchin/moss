# The sessions sidebar (Ctrl+Shift+S): Claude Code's sessions by day, type to filter, Enter resumes one in a new
# tab (claude faked), a running one marked; the claude tab shows its account line (a made-up Max login).
waitfor λ
type python make_sessions.py
key Enter
waitfor sessions-made
key Ctrl+Shift+S
waitlabel session Fix the tab drag drop zones
sleep 500
waitidle
capture out/sidebar.png
type cpu
waitgone session Fix the tab drag drop zones
waitidle
capture out/filtered.png
key Escape
waitlabel session Fix the tab drag drop zones
key Down
key Enter
waitfor fake-claude ready
waitlabel account tester@example.com
sleep 500
waitidle
dump layout
capture out/resumed.png
# its account changes under it: held (the card), what's typed dropped, until "Go on"
type switch-account
key Enter
waitfor fake-claude heard: switch-account
waitlabel account changed
type held
key Enter
sleep 500
waitidle
capture out/account_changed.png
cursorui account go on
lmb down
lmb up
waitgone account changed
type after
key Enter
waitfor fake-claude heard: after
waitidle
capture out/account_go_on.png
# a second claude on the same account logs in to another: it goes on (its own /login), the first is held
cursorui session Fix the tab drag drop zones
lmb down
lmb up
waitfor fake-claude ready
waitlabel account someone.else@example.com
type /login
key Enter
waitfor fake-claude heard: /login
waitlabel account third@example.com
sleep 3500
waitidle
capture out/own_login.png
dump tabs
exit
