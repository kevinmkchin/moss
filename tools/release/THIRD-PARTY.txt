It ships these programs from other people, unmodified, next to moss.exe.

clink (clink\)
  Clink 1.9.34, by Christopher Antos. GNU General Public License v3.0 (clink\LICENSE).
  A separate program that runs inside each tab's cmd. Its source: https://github.com/chrisant996/clink/tree/v1.9.34

clink-completions (clink-completions\)
  clink-completions 0.6.9: tab completion scripts for clink, by Vladimir Kotikov and contributors. MIT License (clink-completions\LICENSE).
  https://github.com/vladimir-kotikov/clink-completions

ConPTY (conpty.dll, OpenConsole.exe)
  The console host from Windows Terminal (Microsoft.Windows.Console.ConPTY), by Microsoft. MIT License
  (conpty-LICENSE.txt). https://github.com/microsoft/terminal

WebView2 loader (WebView2Loader.dll)
  From the WebView2 SDK 1.0.4314.35 (Microsoft.Web.WebView2), by Microsoft. BSD 3-Clause License
  (webview2-LICENSE.txt). It finds the WebView2 Runtime (Microsoft Edge's engine, part of Windows) for web tabs.
  https://www.nuget.org/packages/Microsoft.Web.WebView2
