moss wishlist: features the user wants, not built yet. Remove an entry once it's done.

File browser preview
- The preview uses the full width of the pane (not a side panel next to the list).
- It shows markdown (rendered), images, and text.
- Arrow keys (or the like) cycle through the folder's entries while the preview is open.

Web browser
- A browser in a pane. It need not have every feature of the newest browsers (Chrome and the like), only enough
  for the web apps that matter: Slack, Spotify, x.com, GitHub, reddit.com.
- Stretch goal: youtube.com.
